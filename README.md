## 📚 Competencias de formación SENA (ADSO)

| Área | Lo que trabajo |
|---|---|
| 📝 **Análisis de requisitos** | Levantamiento de requerimientos, especificaciones de software (SRS) y modelado de casos de uso. |
| 🧩 **Diseño de sistemas** | Modelado de datos (diagramas E-R), diseño UML y arquitectura básica de aplicaciones. |
| ⚙️ **Desarrollo y codificación** | Soluciones orientadas a objetos y desarrollo web con buenas prácticas de programación. |
| 🗃️ **Gestión de bases de datos** | Diseño relacional, scripts DDL/DML, consultas complejas, vistas, triggers y procedimientos almacenados. |
| ✅ **Pruebas y calidad** | Validación de requisitos y verificación de la lógica de negocio mediante pruebas de software. |

## 🔍 Intereses tecnológicos

- 🛡️ **Ciberseguridad:** aprender fundamentos de seguridad, redes y buenas prácticas mediante laboratorios autorizados.
- 🐧 **Sistemas operativos:** comprender Linux, la terminal, los procesos, los permisos y la administración del sistema.
- 🖥️ **Hardware y software:** conocer cómo se relacionan los componentes físicos, el sistema operativo y las aplicaciones.
- 🗄️ **Bases de datos:** mejorar en SQL, diseño relacional, consultas, funciones y procedimientos.
- 🧠 **Desarrollo de software:** entender los procesos, justificar las decisiones técnicas y crear soluciones mantenibles.

## 🌱 Mi forma de aprender

Aprendo mejor cuando entiendo el propósito de cada paso y cómo funciona el proceso completo. Me gusta practicar, probar alternativas, identificar errores y documentar lo aprendido. Mi meta es construir una base sólida y poder explicar **por qué** una solución funciona, no solo repetir instrucciones.
